# The marketing surface (/, /pricing, /privacy, /terms, /about, /changelog)
# is fully crawlable. The authenticated dashboard, the API, and the admin
# panel are not — both because they require auth (a crawler will only ever
# see redirects to /login) and because we don't want stale "your team's
# work" URLs cached by search engines.
