# Imported application history

This is a sanitized import of existing application development history, prepared
on November 9, 2026. All imported Git author/committer dates reflect the actual
import time, not original development dates or a November 7 project origin.
Original authorship is retained; importing does not mean contributors authored
new work on this date. Original commit messages are replaced for privacy.

Only previously reviewed application paths are included. Historical operations,
deployment workflows, internal documents, unreviewed paths and private metadata
are omitted. Review policy/configuration pages are normalized; site/contact
examples use reserved example.invalid values. Empty filtered changes may collapse;
meaningful application diffs and supported merge topology are retained. This is
not a complete or byte-identical copy of private history. The current README and
source-review CI are separately reviewed public versions. Deployment stays private.
GitHub issues/PR activity and server timestamps are not rewritten by this import.
